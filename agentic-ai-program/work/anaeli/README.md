# Project 03 — Anaeli

Artifacts folder for the Anaeli build track (P03 in the command center).

This project was added by name only — its workflow inventory starts empty
until the scope is defined. Since it's described as the most advanced project,
two useful first steps in the command center:

1. **INVENTORY** — capture its workflows/opportunities the same way as the
   other projects (or hand the details to Claude to pre-draft them).
2. **VAULT** — mark what already exists as *In progress* / *Complete* so the
   portfolio bar reflects the real head start.

**Data hygiene:** same rule as the parent `work/` folder — no unredacted
customer names, contacts, costs, or margins committed here.
