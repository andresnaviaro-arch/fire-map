# Track B — Automation Studio (5-week elective)

A parallel track covering **AI-powered no-code automation** — the layer below
agents on the escalation ladder. Original material reconstructing the
competencies of university AI-automation courses (opportunity identification →
process mapping → no-code build → pitch & governance → agents bridge), applied
to your real workflow inventories.

## Why this track exists

The core program's first rule is *use the least autonomous system capable of
producing the required business outcome*. Rungs 1–5 of that ladder (prompt
templates, retrieval, deterministic workflows, classifiers, rule engines) are
exactly what no-code automation platforms deliver — cheaper, faster, and more
auditable than an agent. Track B teaches you to build that layer yourself, so
that by the time you build agents (Part III), you reserve them for steps that
genuinely need judgment.

Rule of thumb: **if you can write the steps as a flowchart with no "it
depends," it's an automation, not an agent.**

## Structure

| Week | Theme | Playbook assignment |
|---|---|---|
| B1 | Spot automation opportunities | One-page brief: 2–3 automatable workflows |
| B2 | Map the process A→Z | Detailed automation process map for one workflow |
| B3 | Build with no-code tools + AI | Functional automation connecting ≥2 tools with an AI step |
| B4 | Pitch, adoption & guardrails | Governance framework OR rollout plan |
| B5 | Bridge to agents | Automation upgraded with an agent step + limits assessment |

## How it fits the main program

- Run it **in parallel with Parts I–II**, or standalone.
- Week B1 feeds directly off your command-center inventories: workflows that
  scored **low on judgment complexity** are automation candidates; high-judgment
  ones stay on the agent track.
- Week B3's build is a real deliverable for whichever project supplies the
  workflow (Wesco, InterNavia, or Anaeli).
- Week B5 hands off into Part III — you'll arrive at the B.U.I.L.D. studio
  already owning a working automation to upgrade.

The command center tracks this whole elective under **AUTOMATION STUDIO** in
the PROGRAM module.
