# Project 02 — InterNavia / Interflex — Agent Projects

Artifacts folder for the InterNavia Solutions LLC / Interflex SAS build track.
The command center carries this project as **P02**, pre-seeded with 9 drafted
workflows (proposals, lead intake, used-machine sourcing, listings, parts
quoting, logistics, OEM communication, after-sales, pipeline/cash-flow).

Same method as every project: confirm the inventory → score it → run the
A.G.E.N.T./B.U.I.L.D. cycle on the prime candidate → fill this folder with the
portfolio artifacts (implementation brief, blueprint, eval report, governance
charter, etc.).

Head start: the `generador-propuestas` skill already automates bilingual
proposal generation — treat it as the existing v1 of the proposal-workflow
agent and evaluate/extend it through the Week 8–9 method rather than starting
from zero.

**Data hygiene:** same rule as the parent `work/` folder — no unredacted
customer names, contacts, costs, or margins committed here.
